# Personal Portfolio Website

A clean, responsive four-page personal portfolio built with plain HTML, CSS,
and JavaScript. Deployed on GitHub Pages.

## Live Site

https://rezamaeflores690-gif.github.io/portfolio/

## Built With

- HTML5 (semantic structure)
- CSS3 (flexbox, grid, custom properties, media queries)
- Vanilla JavaScript (mobile navigation, form validation)
- Git & GitHub
- GitHub Pages (hosting)
